# 平板适配验收 · 1.1.0

日期：2026-11-07。范围：优先横竖屏、分屏、触控与安全恢复；没有扩展关卡或改写原存档。

> 补充纠正：下述 1.1.0 的路线/流程测试移除了敌人，Boss 测试含无敌等机制隔离辅助；这些是测试通过，不代表完整正常游戏通关。用户反馈跳不过去后已在 1.1.1 加入保留敌人伤害的多指 AI 回放，见 [可玩性补测记录](PLAYABILITY-QA.md)。

## 本次变化

- 新增 `js/tablet.js` 纯几何布局；横屏触屏默认独立操作面板，竖屏沿用画面上/操作下的结构，紧凑横屏自动悬浮。
- 按键大小、位置、透明度、左右手布局；窄窗口不交叠，▼ 至少 44 CSS px，留出系统安全区。
- 独立多指、指针捕获/释放、滑动换向、取消触点、暂停时清空输入。
- 旋转、明显分屏变化、切后台或失焦均暂停，开场介绍亦暂停；全屏不强制横向锁定。
- 长菜单可滚动，窄分屏暂停菜单不横向溢出；新增中英操作说明、A/B 动作小字、键盘焦点。
- 修复暂停重玩后静音、手柄 Start 不能恢复、暂停快捷键二次消费；仅游玩时请求常亮。
- 升级离线缓存版本，纳入新模块，旧缓存清理限于本游戏前缀。

## 验证结果

### 原游戏全部回归：通过

`npm test` 已实际运行，退出码 0。包含：

- 8 关真实物理路线搜索；24 枚勋章可达性。
- 7 个普通关的旗杆 → 结算 → 下一关流程回放。
- Boss 踩头与火球两种打法，宝珠及结局。
- 60 项机制；死亡累计、成长空间、低顶棚、坏存档容错、后台音频、纪录。

### 平板几何矩阵：通过

`node tools/tablet-layout.cjs`：3024 个组合（1512 个触控可见组合），98 个 DPR 检查。14 组尺寸 × 3 组安全区 × 3 个按键尺寸 × 2 个布局 × 触控开/关 × 左右手 × 3 个高度。

尺寸覆盖 1280×800 / 800×1280、1024×768 / 768×1024、1366×1024 / 1024×1366、1440×900，以及 320×568、360×640、412×915、600×960、640×360、800×500、480×720。

### 输入与恢复：通过

`node tools/tablet-input.cjs`：89 项检查，包括三指同按、单独松手、滑动换向、`pointercancel` / `lostpointercapture`、多键同动作、菜单/空白区防误触、旋转/分屏清空输入、开场后台暂停、重玩音频、手柄 Start 暂停与继续。

## 验证限制

- 这里的平板尺寸是浏览器视口模拟，不代表已经在多款实体平板上长时间手玩。
- 内置浏览器经常报告 `document.hidden`，动画会节流；截图用真实游戏脚本手动推进后渲染，不据此宣称持续 60fps。
- Android/iPadOS 的原生全屏、手势导航、常亮授权及实际握持手感仍需用户设备体验；不支持的 API 静默回退。
- 保留旧 `ssldx:` 存档格式；没有新增长期检查点恢复、存档导入导出或云同步。

## 建议体验

横屏、独立面板、中号按键起步。觉得角色偏小可切回悬浮；觉得按键太低可调「按键位置」。如需分屏，拖动分隔条后会安全暂停，点继续即可。
